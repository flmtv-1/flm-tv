    System Instructions

    Step-by-step guides for common tasks

    Starting the System (Daily)

    • Double-click start-caddy.bat on desktop
    • Wait for "Caddy server running" message
    • Open vMix and start your stream
    • Verify site is live at flmtv.com

    Adding New Movies/Shows

    • Copy media files to the Ugreen NAS shared folder
    • Open Jellyfin at flmtv26.duckdns.org:8920
    • Login with admin credentials
    • Go to Dashboard → Libraries → Scan All Libraries
    • Wait 5-10 minutes for content to appear on site

    Moderating Chat

    • Click "Chat Moderation" in sidebar
    • Click "Refresh Messages" to see latest chat
    • Click "Delete" on inappropriate messages
    • Use "Clear All" only for emergency situations

    Emergency Contacts

    • Tech Support: [Your phone number]
    • If site is down, call immediately
    • If chat has issues, use Chat Moderation section
    • For content issues, check Jellyfin first
