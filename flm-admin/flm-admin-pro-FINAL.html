Services Control

Warning: Only use when instructed

1. Caddy HTTPS Server

Serves the FLM TV website with HTTPS

📍 Desktop → start-caddy.bat

  1. Download the .bat file above
  2. Move it to your Desktop
  3. Double-click to run (requires admin)
  4. Black window opens - DON'T CLOSE IT
  5. Wait for "Caddy server running" message
  6. Website is live at flmtv.com

2. Python HLS Web Server

Serves HLS stream files for live TV

📍 Desktop → FLM-WebServer-Start.bat

  1. Download the .bat file above
  2. Move it to your Desktop
  3. Double-click to run
  4. Server starts on port 8080
  5. Stream available at: http://10.0.0.4:8080/FLMTV.m3u8
  6. Keep window open while streaming

3. FFmpeg Stream (vMix to HLS)

Converts vMix SRT output to HLS format

📍 Desktop → FLM-Stream-Start.bat

  1. Make sure vMix is streaming to SRT port 9000
  2. Download the .bat file above
  3. Move it to your Desktop
  4. Double-click to run
  5. FFmpeg converts stream to HLS format
  6. Output: Desktop\hls\FLMTV.m3u8
  7. Keep window open while streaming

vMix Application Control

Manual control of vMix streaming

  1. Open vMix application
  2. Load your production settings
  3. Click "Stream" button at bottom
  4. Verify green "LIVE" indicator appears
  5. Channel 26.5 is now streaming
  6. To stop: Click "Stream" button again
